    Detailed Description

    class ogl::Camera;

    Creates a virtual camera based on projection matrix. It can be used for both 2D and 3D scenes: it calculates the Projection * View matrix.

    Note: The projection matrix must be updated everytime the screen size is changed.

    This class also provide methods to manage position, mouse sensitivity and camera rotation.
